## Struktura

- `python/`, `php/`, `go/` — kodlar. Fayl nomi: `NNNN-problem-slug.<ext>` (masalan `0001-two-sum.py`)

## Topiclar

- [`array`](topics/array.md) — Massivlar bilan ishlash

- [`math`](topics/math.md) — Matematik masalalar
- [`string`](topics/string.md) — Satrlar bilan ishlash
- [`trie`](topics/trie.md) — Prefiks daraxti (Prefix Tree)
