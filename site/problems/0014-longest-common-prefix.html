G'oya: 7-usul: Pythonic zip usuli

zip(*strs) yordamida barcha so'zlar harfma-harf ustun ko'rinishida siqiladi. Agar ustundagi barcha belgilar bir xil bo'lsa (len(set)==1), u umumiy prefiksga kiritiladi.

Izoh: S nima va nega O(S)?

S nima va nega O(S)? S — massivdagi barcha so'zlar belgilarining umumiy yig'indisi: S = len(s[0]) + len(s[1]) + ... + len(s[n-1]) yoki S ≈ N × M (N — so'zlar soni, M — o'rtacha so'z uzunligi). Nega O(N) emas? Chunki N faqat so'zlar soni bo'lib, har bir harfni solishtirish so'z uzunligi M ga ham bog'liq. Eng yomon holatda barcha S ta belgi tekshirilishi sababli to'liq vaqt murakkabligi O(S) deb belgilanadi.

Yechim usullari sharhi:

  • 1-usul: Vertikal taqqoslash (Vertical Scanning) — O(S) vaqt, O(1) xotira. Ustunma-ustun tekshirish. Amalda eng tezkor, chunki prefiksga kirmaydigan birinchi harfdayoq to'xtaydi.
  • 2-usul: Gorizontal taqqoslash (Horizontal Scanning) — O(S) vaqt, O(1) xotira. Birinchi so'zni asos qilib, qolgan so'zlarga to'g'ri kelguncha oxiridan qisqartirib boradi.
  • 3-usul: Saralash (Sorting) — O(N log N · M) vaqt, O(1) xotira. Alifbo tartibida saralab, faqat birinchi va oxirgi so'zni solishtirish yetarli.
  • 4-usul: Bo'lib ol va hukmronlik qil (Divide and Conquer) — O(S) vaqt, O(M log N) xotira. Massiv ikkiga bo'linib, qismlar prefiksi rekursiv birlashtiriladi.
  • 5-usul: Ikkilik qidiruv (Binary Search) — O(S log M) vaqt, O(1) xotira. Prefiks uzunligi bo'yicha ikkilik qidiruv olib boriladi.
  • 6-usul: Trie (Prefiks daraxti) — O(S) vaqt, O(S) xotira. Barcha so'zlardan daraxt qurilib, bitta shoxli tugunlar zanjiri olinadi.
  • Bonus: Pythonic zip & min/max — O(S) vaqt, O(1) xotira. zip(*strs) yoki min() va max() yordamida eng sodda va toza yechimlar.

    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""

        for i in range(len(strs[0])):
            char = strs[0][i]
            for j in range(1, len(strs)):
                if i == len(strs[j]) or strs[j][i] != char:
                    return strs[0][:i]

        return strs[0]

class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""

        def common(l_str: str, r_str: str) -> str:
            m = min(len(l_str), len(r_str))
            for i in range(m):
                if l_str[i] != r_str[i]:
                    return l_str[:i]
            return l_str[:m]

        def helper(l: int, r: int) -> str:
            if l == r:
                return strs[l]
            mid = (l + r) // 2
            return common(helper(l, mid), helper(mid + 1, r))

        return helper(0, len(strs) - 1)

class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""

        min_len = min(len(s) for s in strs)
        low, high = 1, min_len

        def is_common(length: int) -> bool:
            prefix = strs[0][:length]
            return all(s.startswith(prefix) for s in strs[1:])

        while low <= high:
            mid = (low + high) // 2
            if is_common(mid):
                low = mid + 1
            else:
                high = mid - 1

        return strs[0][:high]

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs or "" in strs:
            return ""

        root = TrieNode()
        for s in strs:
            curr = root
            for char in s:
                if char not in curr.children:
                    curr.children[char] = TrieNode()
                curr = curr.children[char]
            curr.is_end = True

        prefix = []
        curr = root
        while len(curr.children) == 1 and not curr.is_end:
            char = next(iter(curr.children))
            prefix.append(char)
            curr = curr.children[char]

        return "".join(prefix)
